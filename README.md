三渲二到底是什么？从 Blender 建模到卡通质感渲染的核心原理一次讲透
三渲二，简单说就是“用三维模型和三维流程，做出二维动画的观感”。它不是给渲染图加个滤镜，也不是把模型压扁，而是从建模、法线、光照、材质到描边和后期，整套环节都围绕“二维化表达”来设计。理解这一点，才能明白为什么有些人做出来像卡通，有些人却只像低模加描边。

三渲二的核心不是“少细节”，而是“做减法”
三维渲染追求真实光照、复杂材质和连续明暗；三渲二追求的是形状概括、色块明确、阴影分层和轮廓清楚。它保留三维的空间、透视和动作优势，但把连续的光影变化压缩成少数几个色阶。也就是说，三渲二的关键是“控制信息量”：哪里该有硬边，哪里该纯色，哪里该只留一条高光，都要提前设计。

Blender 建模阶段：轮廓比细节更重要
三渲二模型首先要有好剪影。头发、衣褶、装甲边缘如果碎线太多，渲染后容易脏。建模时要注意大块面清楚、转折明确，该硬的地方硬，该圆的地方圆。法线也很关键：平滑法线会让明暗过渡连续，硬边法线能形成清晰色块。三渲二常利用法线控制阴影边界，让受光面和背光面分得干净。模型不需要堆很多细节，但轮廓和结构必须经得起看。

卡通质感的核心原理：把光照“量化”
真实渲染的明暗是渐变的，三渲二则把光照结果分成几档：亮部、中间调、暗部，必要时再加一层边缘光。做法通常是用卡通着色节点或颜色渐变，把光照强度映射成有限色阶，而不是连续灰度。这样画面会出现明确的阴影边界，接近手绘赛璐璐。阴影边界的位置和软硬，取决于光源方向、模型法线和色阶设置。新手常犯的错是色阶太多，结果既不像真实也不像卡通。

描边：三渲二的“骨架线”
描边不是越粗越好，而是要有主次。常见思路有三种：一是用 Freestyle 做轮廓线，适合静态图和动画；二是用实体化修改器配合法线外扩，做出均匀外轮廓；三是用反转壳或后期边缘检测。描边要跟镜头距离和画面尺寸匹配，远景细、近景可略粗。内部结构线要克制，否则画面会碎。描边的颜色也不一定是纯黑，深棕、深蓝往往更自然。

材质与色彩：色块优先，高光克制
三渲二材质要扁平化。基础色尽量纯，明暗靠色阶而不是靠复杂贴图。金属、布料、皮肤可以用不同色阶和边缘光区分，但不要堆真实反射。高光要做成形状明确的小色块，而不是一片模糊亮斑。色彩管理上，保持主色、辅助色、点缀色统一，阴影颜色可以偏冷或偏紫，避免直接加黑导致脏。材质分区清楚，比贴图细节多更重要。

灯光与后期：让画面“像画”
灯光要少而明确，主光决定阴影边界，补光控制暗部信息，边缘光分离主体和背景。背景可以简化成色块或渐变，避免抢主体。后期可以轻微调整对比、色相和描边强度，但不要靠后期补救构图和色阶问题。三渲二的最终目标是让画面有手绘感、色块感和清晰的轮廓秩序。

一句话总结
三渲二不是“三维转二维”的单一技巧，而是用三维模型承载二维审美：建模保轮廓，法线控边界，光照做色阶，描边立骨架，材质压细节，后期统氛围。把这几个原理串起来，Blender 也能做出干净的卡通质感。
